# 漫畫標號器 (LabelPuls_WEB)

一个基于 Flask 的网页版漫画标注工具。把漫画图片和一份 `翻译_0.txt` 放在目录里，启动服务后，在电脑或手机浏览器上给每一格漫画放置编号标号（框内/框外）、填写文字，改动自动写回 txt 文件。

## 功能

- **两种标注模式**：`🏷 標號`（浮岛模式，画布全空、四颗浮岛放标号）和 `✎ 輸入`（双栏模式：左缩略图 + 右清单 + 中央画布）
- **标号分两类**：框内（红）、框外（蓝），点击可随时切换
- **移动端优化**：长按空白新增标号、两指缩放、单指拖动、双击适配视窗
- **电脑快捷键**：滚轮缩放、Ctrl+滚轮翻页、← → 翻页、↑ ↓ 切换标号、Ctrl+Enter 保存、Esc 关闭、＋－0 缩放
- **图片自适应**：按网络质量把大图自动缩到 1000/2000px 供手机加载（`low/med/orig`），并在 `.cache/` 下生成缓存，支持测速与预加载
- **数据持久化**：所有标注实时保存到 `翻译_0.txt`；没有该文件时会根据目录内图片自动生成
- **多设备访问**：局域网内手机/平板直接开浏览器就能用

## 安装

需要 Python 3（建议 3.9+）：

```bash
pip install -r requirements.txt
```

依赖仅两个：`Flask`、`Pillow`（Pillow 可选，缺失时只影响图片压缩，不装也能跑）。

## 快速开始

### 准备素材

把要标注的漫画图片（`.png/.jpg/.jpeg/.webp/.bmp/.gif/.tif/.avif`）放到项目目录（或任意子目录），例如：

```
my_comic/
  001.png
  002.jpg
  003.webp
```

### 启动

**Windows 一键启动**：双击 `start_server.bat`（可选拖入素材目录，或用命令行 `start_server.bat "D:\my_comic"`）。脚本会自动杀掉占用 5000 端口的旧进程。

**命令行启动**：

```bash
python main.py            # 使用当前目录作为素材目录
python main.py "D:\my_comic"   # 指定素材目录
```

启动后控制台会打印网址：

```
http://127.0.0.1:5000       # 本机
http://192.168.x.x:5000     # 局域网内手机/平板访问用这个
```

> 注意：服务器挂在启动它的窗口上，按 `Ctrl+C` 停止。

### 开始标注

1. 打开网址，进入 **標號** 模式
2. **长按图片空白处**（电脑右键）弹出菜单：新增「框内」或「框外」标号
3. 点击标号 → 底部弹出输入栏，填写文字；`↕` 切换框内/框外，`🗑` 删除
4. 顶部 `🏷 標號 / ✎ 輸入` 切换模式，`質量` 切换图片清晰度，`重測` 测网速，`＋/−` 调标号大小
5. 右上角 `?` 随时查看完整操作说明

## 数据格式（翻译_0.txt）

所有标注保存在 `翻译_0.txt`（UTF-8）。格式如下：

```
1,0
-
框内
框外
-
Default Comment
 You can edit me

>>>>>>>>[001.png]<<<<<<<<
----------------[1]----------------[0.456,0.210,1]
对话文字
----------------[2]----------------[0.720,0.530,2]

>>>>>>>>[002.jpg]<<<<<<<<
```

- `>>>>>>>>[图片名]<<<<<<<<`：每个图片一个区块
- `----------------[id]----------------[x,y,inside]`：标号位置（0~1 坐标）与类型（`1`=框内，`2`=框外），下一行是文字
- 若目录里没有 `翻译_0.txt`，服务会自动按图片生成一份空的

## 项目结构

```
main.py              入口：启动 Flask 服务，打印访问地址
start_server.bat     Windows 一键启动脚本
requirements.txt     依赖（Flask, Pillow）
core/comic.py        txt 文件的解析 / 生成 / 保存
ui/app.py            路由 + 前端页面（单文件 HTML/JS）
utils/network.py     获取局域网 IP
backup/              旧版本备份
```

## 常用 API

| 路径 | 说明 |
| --- | --- |
| `/` `/label` `/input` | 页面（重定向到第一张图） |
| `/mark/<img>` `/input/<img>` | 某张图的标注/输入页 |
| `/api/get_dialogues?img=` | 取某图所有标号 |
| `/api/save_dialogues` | 保存某图所有标号 |
| `/api/update_text` | 更新单条标号文字 |
| `/image/<file>` | 取原图 |
| `/image_variant/<width>/<file>` | 取缩放后的图 |
| `/api/config` | 读写 `config.json`（标号大小等） |
| `/api/speed_test` | 测速（返回小图测下载速度） |
| `/api/prewarm` | 预生成附近图片的缩放缓存 |
| `/debug/list_files` | 列出素材目录（调试用） |

## 环境变量（可选）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PREWARM_COUNT` | `8` | 启动时预生成缓存的前 N 张图 |
| `NEIGHBOR_PREWARM_RADIUS` | `2` | 翻页时预生成相邻多少张的缓存 |

## 已知限制

- 单用户本地使用场景，未做多用户并发控制
