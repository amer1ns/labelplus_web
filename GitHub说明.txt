漫畫標號器 (Comic Labeler)
基于 Flask 的网页版漫画标注工具。在浏览器（手机/电脑）上给漫画图片放编号标号、填文字，改动自动写回翻译_0.txt。

功能
- 两种模式：標號（浮岛放置）/ 輸入（缩略图+清单+画布）
- 标号分框内（红）、框外（蓝），点击即切换
- 移动端手势：长按新增、双指缩放、双击适配
- 电脑快捷键：滚轮缩放、Ctrl+滚轮翻页、方向键切标号、Ctrl+Enter 保存
- 图片自动压缩缓存，手机加载快

使用方法
1. 安装依赖：pip install -r requirements.txt （Flask + Pillow）
2. 把漫画图片放到项目目录（或任意目录）
3. 启动：
   - Windows：双击 start_server.bat（会杀旧进程，自动起服务）
   - 命令行：python main.py 或 python main.py "图片目录"
4. 打开控制台打印的网址：
   - 本机 http://127.0.0.1:5000
   - 手机/平板用局域网 IP（如 http://192.168.x.x:5000）
5. 长按空白处（电脑右键）新增标号 → 点击标号输入文字 → 自动保存到翻译_0.txt

数据文件翻译_0.txt（UTF-8，自动生成）
  每张图一个区块，图片名用 >>>>>>>>[001.png]<<<<<<<< 分隔；
  每条标号是 ------------------[1]-----------------[x,y,inside]（1=框内 2=框外）加一行文字。

注意
- start_server.bat 需自行改成自己的 Python 路径
- 服务器挂在启动窗口上，Ctrl+C 停止
